# Responsive Developer Resume Web Page

[![Language](https://img.shields.io/badge/Language-HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![Styling](https://img.shields.io/badge/Styling-CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![Design](https://img.shields.io/badge/Layout-Responsive_Cards-brightgreen?style=flat-square)](#features)

A modern, responsive online developer resume template built with HTML5 and CSS3, presenting software engineering experience, skillsets, education history, and contact methods in a visually appealing card-based format.

---

## Features

- **Profile Card & Avatar**: Professional portrait integration with concise biographical summary.
- **Categorized Skills Matrix**: Visual badges and skill tags for programming languages and frameworks.
- **Education & Experience Timelines**: Structured chronological presentation of academic credentials.
- **Direct Contact Links**: Integrated email, LinkedIn, and phone shortcuts.
- **Mobile Responsive**: Adapts fluidly to phone, tablet, and desktop viewports.
